# Cart Blanche

A phone-first home bar cart manager: track what's in the cart, see which cocktails you can make (IBA official specs plus bar classics), and keep a shared shopping list.

Live at https://annyong333.github.io/cart-blanche/ — open in Safari and use Share → Add to Home Screen.

- `firebase-config.js` — paste a Firebase web config to turn on household sync (null = this phone only).
- Photo label reading uses an Anthropic API key entered in the app's Settings.
